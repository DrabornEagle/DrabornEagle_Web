# DraBornBuy web yayını

[DraBornBuy Android ve web ortak kaynak deposu](https://github.com/DrabornEagle/DraBornBuy) burada kullanılan tek uygulama kaynağıdır. Bu depodaki `.github/workflows/dkd_company_pages.yml` her yayın işleminde kaynak depoyu klonlar ve Expo web çıktısını Pages artefaktındaki `DraBornBuy/` dizinine üretir. Böylece [www.draborneagle.com/DraBornBuy/](https://www.draborneagle.com/DraBornBuy/) ve Expo Go aynı ekranları ve Supabase verilerini kullanır.

GitHub deposundaki bu klasör yayın hedefinin belgesidir; dağıtımdaki `index.html`, `_expo/` ve `assets/` dosyaları her çalışmada otomatik oluşturulur. `DKD-SOURCE.txt` yayınlanan kaynak commit'ini gösterir. Servis anahtarları ve banka bilgileri burada tutulmaz.
