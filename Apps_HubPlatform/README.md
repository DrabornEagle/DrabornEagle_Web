# DraBornEagle HubPlatform

Bu klasör HubPlatform projesinin repo giriş noktasıdır.

## Canlı adres

`https://www.draborneagle.com/Apps/HubPlatform/`

## Üretim dosyaları

GitHub Pages URL yapısının `/Apps/HubPlatform/` olarak çalışması için yayınlanan statik dosyalar `Apps/HubPlatform/` altında tutulur. `Apps_HubPlatform/index.html` eski/alternatif repo yolundan resmi adrese yönlendirir.

## Projeler

- DraBornGo
- DraBornGames
- DraBornGate
- DraBornPark
- DraBornTrips
- DraBornMarket
- DraBornStyle

Proje metinleri, durumları, özel web sayfası ve Google Play bağlantıları `Apps/HubPlatform/dkd-hub.js` içindeki `dkdProjects` kaydından merkezi olarak yönetilir.

Tasarım dili DraBornGames ile aynı ürün ailesini korur: koyu zemin, büyük tipografi, canlı vurgu renkleri, güçlü kart yapısı ve mobil öncelikli responsive düzen. Yeni arayüzde gölge, glow ve gradient kullanılmaz.
